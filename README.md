# ✨ 提示词优化助手（Prompt Optimizer）for DeepSeek Harness

> **当前最新版本：v0.11.5**（安装到你电脑上的版本可在 设置 → 插件 → 提示词优化 的标题旁查看）

一款为 DeepSeek Harness（DSH）对话界面自制的小插件：在输入框旁边加一个「✨ 优化」按钮，一键把你的草稿变得更清楚、更有条理。适合不想反复改提示词、想让 AI 一次听懂你意思的朋友。

## 它能帮你做什么？

- 点一次 ✨：自动把输入框里的草稿改写成更清晰、更具体的提示词（就像请一位提示词老手帮你润色）。
- 改完直接用：输入框自动变成优化后的版本，你直接点发送就行。
- 不想要？点「↩ 撤销」还原成你的原文，不留痕迹。
- 原文可对照：优化前的原文会轻量显示在输入框上方，方便对比，发送时不会带出去。
- 不打扰对话：优化只是单独问一次模型，不会把过程塞进你和 AI 的对话里。
- 想关就关：设置里一键停用/启用，不用重启也能马上生效。

## 安装前，先认识 3 个词

- **DeepSeek Harness（简称 DSH）**：运行 AI 对话的程序（网页版界面），你平时聊天用的就是它。
- **终端（PowerShell）**：一个可以输入命令的小黑窗口。Windows 下：点「开始」→ 搜索「PowerShell」→ 打开蓝色图标的应用，后面的命令都粘贴进这个窗口并按「回车」执行。
- **pnpm**：一个帮你下载安装小工具的小帮手，我们马上会装上它。

## 安装步骤

> 前提：你的电脑已经装好 DSH 并能正常聊天。下面所有命令都在「终端」里执行。

**第 1 步：安装 pnpm（只需一次）**

```powershell
npm install -g pnpm
```

如果提示“npm 不是内部或外部命令”，说明还没装 Node.js——请先让帮你装机的人装好 Node.js 再回来。

**第 2 步：把插件安装到 DSH**

**方式一：直接从 GitHub 安装（推荐给所有人，最简单）**

```powershell
dsh plugin --profile web add github:naitoupi/prompt-optimizer-plugin
```

**方式二：从本地文件夹安装（比如你自己下载了源码）**

```powershell
dsh plugin --profile web add 插件文件夹的完整路径
```

路径示例（把下面路径换成你自己的）：

```powershell
dsh plugin --profile web add C:\Users\你的用户名\Desktop\prompt-optimizer-plugin
```

（如果你是从 GitHub 下载的压缩包，解压后找到里面 `package.json` 所在的文件夹，把它的完整路径填进来即可。）

看到类似 `+ prompt-optimizer-plugin link:...` 和 `Done in ...` 就是成功了。这个插件没有构建步骤，安装时不会运行任何代码，简单又安全。

**第 3 步：重启 DSH**

先关掉正在运行的 DSH 窗口，再重新启动：

```powershell
dsh web
```

浏览器会自动打开界面（如果没自动打开，手动访问 http://127.0.0.1:3080）。

## 快速上手

1. 在 DSH 界面新建一个对话；
2. 在输入框里写下你的草稿（比如“帮我写个二分查找”）；
3. 点输入框旁边的 **✨ 优化** 按钮；
4. 输入框自动变成优化后的版本，上方出现「📋 原文」参考区；
5. 满意就直接点发送；不满意点 **↩ 撤销** 恢复原文，或改一改再优化一次。

想调整优化效果？点右上角 **设置 → 插件 → 提示词优化**：

- 「停用插件 / 启用插件」：一键开关（立即生效，不用重启）；
- 「生成参数」：思考强度、最大输出长度、温度——改完点「保存参数」；
- 「优化指令」：可以查看和修改模型收到的规则，改完点「保存指令」，想回到初始版本点「恢复默认指令」。

## 常见问题

**Q1：输入框旁边没有 ✨ 按钮？**

先重启一次 DSH（`dsh web`）；再进 设置 → 插件 → 提示词优化，确认不是「已停用」（是的话点「启用插件」）；最后新建一个对话试试（已经打开的旧对话可能没刷新）。

**Q2：点优化后出现红字提示？**

大多数情况是草稿里没有明确要求（比如只是一句陈述）。在草稿里加上“请帮我…”“改写成…”之类的指令再试一次。红字本身也会写明具体原因，照着做就行。

**Q3：优化速度有点慢？**

进 设置 → 插件 → 提示词优化，把「思考强度」设为 off（默认值就是）。如果还是很慢，检查一下你选择的模型是否较快。

**Q4：想彻底卸载这个插件？**

在终端执行：

```powershell
dsh plugin --profile web remove prompt-optimizer-plugin
```

然后重启 DSH 即可。

## 小提示

- 插件所有设置（开关、参数、自定义指令）都存在你的电脑上：`~/.dsh/prompt-optimizer-state.json`，删除这个文件等于把所有设置恢复成初始状态。
- **版本号**：当前安装的版本可在 设置 → 插件 → 提示词优化 的标题旁查看（如 v0.11.3）。
- **界面语言**：插件自动跟随 DSH 界面语言（英文界面显示英文，中文界面显示中文）；内置默认优化指令也是双语的——中文界面显示中文模板、英文界面显示英文模板，模型仍会按“与原文同语言”的要求用你的语言输出结果。
